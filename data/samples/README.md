# Documentos de exemplo (gabarito "golden")

Coloque aqui:

- 2 a 4 apólices D&O públicas (PDF), incluindo pelo menos 1 escaneada/baixa qualidade para
  exercitar o OCR. Cite a fonte de cada arquivo no Relatório Técnico.
- Em `tests/golden/`, um JSON por apólice anotado manualmente com os campos principais
  (seguindo o esquema `ApoliceDO`), usado para medir a acurácia da extração.

Não inclua documentos confidenciais ou com dados pessoais reais (seção 10 da spec).
